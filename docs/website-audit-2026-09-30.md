- MPP merchant and agent-wallet validation remains external; direct settlement is disabled. The agent can use hosted Checkout once exact production billing configuration exists, subject to payer consent/bank authentication.
- Full real Advanced source-to-provider cycle and documented 24-hour SLO canary sample remain unproved. Runtime pairing/lifecycle/WSL/macOS acceptance and LinkedIn provider approvals remain separate live exercises.
