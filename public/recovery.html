RECOVERY

Exact recovery checkpoints

Checkpoints capture an exact Cloudflare Durable Object bookmark plus non-secret release and state-summary metadata. Raw bookmarks stay on the server and are never shown in the browser.

Preparing a restore quarantines publication. It does not execute the restore. Execution still requires the exact typed workspace confirmation in the main workspace. 


      

      

        

          Approximate timestamp recovery
          

            Compatibility path only. Cloudflare maps a requested time to an approximate bookmark. It is not silently substituted for an exact checkpoint and may be unavailable even when exact checkpoint restore is healthy.
