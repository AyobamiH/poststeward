# PostSteward operational timers
The user systemd manager on web dispatches the three observation workflows on their original UTC schedules. Install dispatch.py under ~/.local/share/poststeward-monitor-clock and install the service and timers under ~/.config/systemd/user. Enable the timers after the matching workflow definitions reach main. The operator account needs authenticated GitHub repository dispatch access. No Cloudflare or provider credentials belong in the timers.

Each workflow run displays its UTC slot and executes on the PostSteward operations runner. Check both staging and production jobs where applicable. The service journal records submission and ~/.local/state/poststeward-monitor-clock holds the last slot for each monitor. A submission receipt establishes GitHub acceptance only. If submission was interrupted, compare the slot with the GitHub run history before retrying. Persistent timers coalesce missed slots after downtime. To stop scheduling, stop and disable the three poststeward-clock timers.
